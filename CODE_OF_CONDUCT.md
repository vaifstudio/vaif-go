# Code of conduct

This project has adopted the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
as its code of conduct. It applies in this repository's issues and pull
requests, and wherever someone represents the project.

In summary: be respectful and considerate, accept constructive feedback, and
do not harass, insult or demean anyone, publish anyone's private information,
or behave in ways that would be inappropriate in a professional setting.

## Reporting

Report conduct that violates the code of conduct to support@vaif.studio. The
maintainers review every report, respond to the person who made it, and keep
the reporter's identity private. They may remove comments, commits, issues and
other contributions, and may block anyone who violates the code of conduct.
